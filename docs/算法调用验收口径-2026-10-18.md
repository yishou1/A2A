# 算法调用验收口径

根据用户 2026-10-18 的最新要求，本阶段只验收算法能否正常真实调用，不以精度、召回率、类别恢复效果或业务效果作为通过条件。

## 通过条件

1. 服务可访问，所需运行依赖和模型可以加载。
2. 使用符合输入契约的请求，通过实际使用的调用入口执行成功；既有 HTTP 又有 AlgoLib 入口的模块分别记录。
3. 响应成功，结果字段和类型符合输出契约，无未捕获异常。
4. 执行真实实现；Mock、stub 和固定演示返回单独记录，不计为真实调用通过。

健康检查成功、注册为 active、模型文件存在，均不能单独代替一次成功的实际调用。不同设备需要重新验证部署和调用；本机记录不代表其他设备已经通过。

## 与公开数据验收的关系

保留原有公开数据报告和固定标准文件，便于追溯。本阶段不再将其中的 ARI、预测误差等质量指标作为调用可用性的通过条件，也不因为精度暂不考核而跳过输入、输出或真实执行检查。

后续实际执行测试范围仍限于通用、非作战模块；面向目标威胁排序、攻击决策和武器火控等能力，仅保留只读状态记录，不进行能力打通或增强。
