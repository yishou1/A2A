## 一、新设备首次部署

### 1. 拉取代码

```powershell
git clone <算法库仓库地址>
cd A2A-lkf-algorithmrepo
```

如果已经克隆：

```powershell
git pull
```

编译产物、Python虚拟环境和本地注册表不会从Git中拉下来，每台设备需要重新生成。

### 2. 创建Python环境

```powershell
conda create -n algorithm_repo python=3.10 -y
conda activate algorithm_repo

python -m pip install -r .\services\requirements.txt
```

检查：

```powershell
python -c "import fastapi, uvicorn, torch, onnxruntime; print('python dependencies ok')"
```

### 3. 编译算法库网关

普通Python HTTP算法调用：

```powershell
cmake -S . -B build
cmake --build build --config Release
```

产物通常是：

```text
build\Release\algolib.exe
build\Release\algolib_server.exe
```

如果使用M04、M16等原生ONNX算法，需要配置ONNX Runtime C++ SDK：

```powershell
cmake -S . -B build `
  -DALGOLIB_WITH_ONNXRUNTIME=ON `
  -DALGOLIB_ONNXRUNTIME_ROOT="C:\path\to\onnxruntime"

cmake --build build --config Release
```

## 二、每次使用时启动

### 终端1：启动全部本地Python算法服务

```powershell
conda activate algorithm_repo

.\scripts\start_a2a_algorithm_services.ps1 `
  -Python "D:\software\Miniconda3\envs\algorithm_repo\python.exe"
```

端口冲突已经处理，当前本地服务使用唯一端口 `9010–9038`。

注意：当前脚本会设置：

```text
TIA_USE_MOCK=1
```

因此适合先保证所有接口、Schema和Agent调用链正常。如果要严格加载正式模型，需要后续给脚本增加真实模式参数。

### 终端2：启动算法库统一网关

Debug版本：

```powershell
New-Item -ItemType Directory -Force .\.algolib

.\build\Debug\algolib_server.exe `
  --host 127.0.0.1 `
  --port 8088 `
  --registry .\.algolib\registry.json `
  --execution-log .\.algolib\executions.jsonl
```

Release版本：

```powershell
.\build\Release\algolib_server.exe `
  --host 127.0.0.1 `
  --port 8088 `
  --registry .\.algolib\registry.json `
  --execution-log .\.algolib\executions.jsonl
```

检查网关：

```powershell
Invoke-RestMethod http://127.0.0.1:8088/health
```

Agent只需要连接8088，不需要知道9036、9037、9038等内部端口。

## 三、首次注册并激活算法

每台设备首次部署时需要执行一次。之后只要继续使用同一个：

```text
.algolib\registry.json
```

就不需要每次重新注册。

以M20为例：

```powershell
$base = "http://127.0.0.1:8088"

$body = @{
    package_or_card_path = (
        Resolve-Path .\examples\graph_relation_reasoner\1.0.0
    ).Path
} | ConvertTo-Json

Invoke-RestMethod `
  -Method Post `
  -Uri "$base/algorithms/register" `
  -ContentType "application/json" `
  -Body $body
```

验证：

```powershell
Invoke-RestMethod `
  -Method Post `
  -Uri "$base/algorithms/graph_relation_reasoner/1.0.0/python_http_service/validate"
```

激活：

```powershell
Invoke-RestMethod `
  -Method Post `
  -Uri "$base/algorithms/graph_relation_reasoner/1.0.0/python_http_service/activate"
```

检查是否能被Agent发现：

```powershell
Invoke-RestMethod `
  "$base/algorithms?capability=graph_relation_reasoner&active_only=true"
```

## 四、Agent如何发现算法

Agent收到任务后，根据任务提取能力，例如：

```text
需要多目标跟踪 → multi_object_tracking
需要损伤评估   → damage_assessment
需要图关系推理 → graph_relation_reasoner
```

然后查询：

```http
GET http://127.0.0.1:8088/algorithms?capability=multi_object_tracking&active_only=true
```

PowerShell验证：

```powershell
$result = Invoke-RestMethod `
  "$base/algorithms?capability=multi_object_tracking&active_only=true"

$result.algorithms |
  Select-Object algorithm_id, version, backend_type, capabilities
```

Agent还可以读取算法详情：

```http
GET /algorithms/{algorithm_id}/{version}/{backend_type}
```

例如：

```powershell
Invoke-RestMethod `
  "$base/algorithms/motr_neural_kalman_tracker/1.0.0/python_http_service"
```

读取输入Schema：

```http
GET /algorithms/{algorithm_id}/{version}/{backend_type}/files/input.schema.json
```

## 五、Agent统一调用算法

所有算法统一通过：

```http
POST http://127.0.0.1:8088/run
```

例如M20：

```powershell
$body = Get-Content `
  .\examples\graph_relation_reasoner\1.0.0\golden_cases\case_001_request.json `
  -Raw

Invoke-RestMethod `
  -Method Post `
  -Uri "$base/run" `
  -ContentType "application/json" `
  -Body $body
```

统一请求结构：

```json
{
  "request_id": "agent-request-001",
  "trace_id": "agent-trace-001",
  "algorithm_id": "graph_relation_reasoner",
  "version": "1.0.0",
  "backend_type": "python_http_service",
  "inputs": {
    "tracks": []
  },
  "params": {}
}
```

## 六、Agent侧最小调用代码

```python
import requests

BASE_URL = "http://127.0.0.1:8088"


def find_algorithms(capability: str) -> list[dict]:
    response = requests.get(
        f"{BASE_URL}/algorithms",
        params={
            "capability": capability,
            "active_only": "true",
        },
        timeout=10,
    )
    response.raise_for_status()
    return response.json()["algorithms"]


def run_algorithm(
    algorithm: dict,
    inputs: dict,
    *,
    request_id: str,
    trace_id: str,
) -> dict:
    request = {
        "request_id": request_id,
        "trace_id": trace_id,
        "algorithm_id": algorithm["algorithm_id"],
        "version": algorithm["version"],
        "backend_type": algorithm["backend_type"],
        "inputs": inputs,
        "params": {},
    }

    response = requests.post(
        f"{BASE_URL}/run",
        json=request,
        timeout=60,
    )
    response.raise_for_status()
    return response.json()


candidates = find_algorithms("graph_relation_reasoner")

if not candidates:
    raise RuntimeError("没有可用的图关系推理算法")

selected = candidates[0]

result = run_algorithm(
    selected,
    inputs={
        "tracks": [
            {
                "track_id": "T-001",
                "object_type": "aircraft",
                "lat": 31.242,
                "lon": 121.512,
                "speed": 230,
                "heading": 86,
            }
        ]
    },
    request_id="req-001",
    trace_id="trace-001",
)

print(result)
```

关键结论：

- 新设备首次使用：安装依赖、编译、注册、激活。
- 每次运行：启动Python算法服务和8088网关。
- Agent只访问8088。
- Agent通过算法卡的 capability 和Schema选择算法。
- Agent统一通过 `POST /run` 调用。
- `.algolib/registry.json` 要保留，否则需要重新注册激活。
