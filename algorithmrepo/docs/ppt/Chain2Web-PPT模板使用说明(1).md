# Chain2Web PPT模板使用说明



- 正文采用浅色底、深蓝标题、青色强调的架构型视觉；
- 架构图、流程图、Agent、算法和技能均使用可编辑PPT形状。



## 协作规则

- 成员只能复制既有页面和组件，不得修改主题色、字体或页脚；
- 内容负责人提交事实、来源、实现状态、建议图形和讲稿；
- 大模型可以帮助压缩文字，但不得补充项目事实；

## 图片和矢量要求

- 架构图、流程图、图标和标注必须使用PPT原生形状或SVG；
- 系统截图和真实照片无法成为矢量图，应作为证据类图片使用；
- 本模板中的两项位图例外是学校标识和系统真实界面；

## 术语和颜色

| 对象 | 颜色 |
|---|---|
| 任务/主流程 | 学校蓝 |
| Agent | 蓝色 |
| 技能 | 青绿色 |
| 算法 | 紫色 |
| 异常 | 红色 |
| 证据/提醒 | 橙色 |

不要在同一份PPT中引入第二套图标、颜色或卡片风格。
