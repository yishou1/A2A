## 启动方式（对齐后）

```powershell
# 1) 算法服务 + 集中网关
.\scripts\start_a2a_algorithm_services.ps1 -TiaOnly

# 2) TIA Agent
$env:TIA_NACOS_REGISTER="0"
$env:TIA_PORT="8016"
$env:ALGOLIB_BASE_URL="http://127.0.0.1:8088"
$env:TIA_ALGOLIB_CALL_MODE="run"
# 动态选算法（可选）
# $env:TIA_ALGORITHM_PLANNER="llm"
# $env:ENABLE_LLM="true"
# $env:TOOL_LLM_URL="http://127.0.0.1:8000/v1"
# $env:TOOL_LLM_NAME="qwen2.5-7b-instruct"
python -m tactical_intelligence_agent.main
```

有 Nacos 时默认 `TIA_NACOS_REGISTER=1`，会按心跳间隔上报资源与 `skill_ids`。

## Commander 调用约定

- `required_skill`: `tactical_intelligence_analysis`
- `output_hint`: `intelligence_packet`
- `command`: `process_intelligence`
- 业务输入：`input.agent_request`（见 `docs/TIA_COMMANDER_IO_SHELL.md`）
- 落库键：`context.intelligence_packet`（role=`tactical_intelligence`）
- 下游取数：`tracks`（航迹预测）/ `targets`（决策）/ `task_schedule`（调度）/ `output_attachments`（BDA）
- 真实演练：无 mock 兜底，需提供传感器 `attachments` 或业务输入字段

## 用 lzh 同款小模型验证动态选算法

lzh `tests/test_llm_client.py` 默认：

- `TOOL_LLM_URL=http://127.0.0.1:11434/v1`（Ollama）
- `TOOL_LLM_NAME=qwen3:1.7b`
- `API_KEY=ollama`

```powershell
# 1) 启动与 lzh 相同的本地小模型
ollama serve
ollama pull qwen3:1.7b

# 2)（可选）起算法网关，便于 catalog_source=algolib:/algorithms
.\scripts\start_tia_algolib_gateway.ps1

# 3) 验证：真 LLM 产出 TIA algorithm plan
.\.venv\Scripts\python.exe scripts\verify_tia_llm_lzh_ollama.py
```

通过标准：`mode=llm`，必含 detector/edl/motr，计划写入 `data/output/verify_tia_llm_lzh/llm_plan.json`。
