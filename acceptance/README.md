# 通用算法公开数据验收

本目录补充通用数学软件的验收证据，不用于作战效能评估，也不把整个算法库标记为验收通过。

用户已将当前阶段要求调整为“只验收正常真实调用，暂不考核精度”。当前口径和全库已有证据分类见 [算法调用验收口径](../docs/算法调用验收口径-2026-10-18.md)。下述固定标准与历史报告保留用于追溯，质量指标不再作为当前调用可用性的通过条件。

## 数据与标准

- `public_data/` 保存 UCI Iris、Wine 的原始数据、来源说明、CC BY 4.0 署名和 SHA-256。
- `generic_criteria.json` 在首次运行前确定。当前版本为 1.0.0，原始 SHA-256 为 `6c3414db69693e3f12526fae3a6e2a70212e78abd1fe2254c4d5d69e64189eff`。
- 标准是本轮提出的工程测试标准，尚不是用户批准的生产 SLA。失败时保留结果，不根据结果降低阈值、改标注或偷偷更换数据。

## 如何重跑

启动项目后双击根目录 `运行通用算法验收.bat`，或运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/accept-generic.ps1
```

入口会把已存在的数据、标准和脚本送入当前核心容器，使用独立注册表和执行日志。每轮使用新的输出目录，不改变项目活动注册表，不启动仿真或执行业务工作流。结果保存在 `.runtime/generic-acceptance/<run-id>/`，最新报告位置记录在 `.runtime/generic-acceptance/latest-report.txt`。

测试不自动下载数据。源码交付已包含数据；只有有意更新来源时才运行 `python scripts/fetch_generic_acceptance_data.py --refresh`。

## 验证内容

| 模块 | 实际检查 |
| --- | --- |
| K-Means | 两套公开数据；标准化；与 scikit-learn 的惯性值比较；外部标签 ARI；收敛、成员、中心与重放一致性 |
| DBSCAN | 两套公开数据；与 scikit-learn 的分区及噪声集合比较；成员/中心、非退化和重放检查 |
| FedAvg | 用公开植物/化学测量数据构建三个本地岭回归参数；对照独立 NumPy 加权平均；参与数、权重与张量形状检查 |
| 输入契约 | 正常、空、重复、形状不一致、布尔伪数值、缺必填字段等用例；同时检查 HTTP 与 AlgoLib |
| 调用链 | 两条路径均使用 `require_real=true`，检查 deterministic 模式、输出一致性和暂定单次耗时预算 |

报告保存输入请求、请求/响应哈希、依赖版本、实现源文件哈希、标准哈希及逐项结果。不要把大量测试用例数当成大量算法数。

## 必须保留的解释

DBSCAN 与参考实现完全一致，只能支持“相同参数下实现正确”的结论。Wine 上的类别标签不一定形成该参数下的密度簇；本轮观察到类别恢复很差，因此没有认证它适合 Wine 类别恢复任务，也没有为此调参。

FedAvg 的验收对象是加权参数聚合计算。所报告的留出集回归误差仅供观察，不是联邦训练收敛、隐私保护或生产模型精度认证。

K-Means 的公开小数据分数和单次耗时不代表任意业务数据、并发规模或其他设备的表现。模型文件结构检查、真实执行路径检查和应用精度验收分别记录，不能相互替代。
