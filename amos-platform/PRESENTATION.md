# 页面演示说明

当前页面可从顶部“当前场景”选择“临海多域协同侦察与精确打击”“空天海航母编队联合对陆打击”或既有剧本。

## 查看顺序

1. 场景态势：显示当前资料和事件记录；运行状态保留在顶部与底部状态栏。
2. Agent 拓扑：首层显示六个功能角色，点击“查看角色与算法”展开技术详情。设备算力映射单独折叠，并分别统计平台、设备、算力节点和部署关系。
3. 算法与功能：显示当前任务关联算法数量及全局目录；未连接运行时时，运行包等数量显示“未知”。
4. 流程执行：查看既有的分析活动及运行记录。
5. 证据与结果：查看报告和运行记录。分析失败的错误原因保留在原有状态栏；停止或结束时可继续查看資料并导出记录。

## 页面操作

- 默认工作区占视口宽度 46%；已有的用户拖动宽度设置仍优先。可拖动中间分隔条，或点击“展开工作区”专注查看，再点击“恢复双栏”。
- 资料缩略图显示标题与时间。点击打开完整大图；采集参数和消费关系可展开查看。支持 Escape 关闭、Tab 在对话框内移动，关闭后恢复焦点。
- 资源名称不再按固定字符数截断。电量与燃油按实际字段显示；缺失数据保持“未提供”，零值保持为零。
- 地图坐标标注为“鼠标坐标”；移动地图或离开地图后清除旧指针位置。
- 已按用户要求移除介绍性状态卡、节点说明、媒体说明及类似文案，保留实际状态与操作信息。
